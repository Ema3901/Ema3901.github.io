creacion.md

Creación

Este Generador de Códigos QR nació de la necesidad de crear una herramienta simple, rápida y accesible para generar códigos QR sin depender de servicios online.

Muchas veces necesitaba crear códigos QR para compartir enlaces, información de contacto o texto, pero las herramientas web disponibles tenían limitaciones como:

  • Dependencia de internet: Requieren conexión constante.
  • Privacidad: Los datos se procesan en servidores externos.
  • Limitaciones gratuitas: Restricciones de uso o marcas de agua.
  • Falta de personalización: Opciones limitadas de configuración.
objetivos.md

Objetivos del Proyecto

  • Generar códigos QR de alta calidad instantáneamente.
  • Mantener total privacidad de los datos (procesados localmente).
  • Proporcionar una interfaz intuitiva para usuarios no técnicos.
  • Ser completamente portable y ejecutable sin instalaciones complejas.
desafios.md

Desafíos Enfrentados

Durante el desarrollo me encontré con varios retos interesantes:

  • Interfaz de Usuario Intuitiva: Tkinter puede verse "anticuado", así que mejoré la experiencia visual con estilos personalizados y distribución lógica.
  • Gestión de Archivos y Rutas: Sistema robusto que funcionara en distintos SO y validara nombres de archivos.
  • Validación de Entrada: Flexible con contenido (URLs, texto, emails) pero estricto con nombres de archivos.
  • Experiencia del Usuario: Confirmaciones antes de sobrescribir, apertura automática de carpeta y mensajes claros.
aprendizajes.md

Lo que Aprendí

  • Desarrollo de GUI con Python: Layouts, eventos y UX con Tkinter.
  • Distribución de Software: Empaquetado con PyInstaller y compatibilidad multiplataforma.
  • Manejo de Librerías Externas: Integración de qrcode.
  • Pensamiento Centrado en el Usuario: Casos de uso reales y edge cases.
evolucion.md

Evolución del Proyecto

La aplicación comenzó como un script simple de consola y evolucionó hacia una aplicación completa de escritorio. Las mejoras incluyeron:

  • Interfaz gráfica completa
  • Sistema de logging y feedback visual
  • Gestión inteligente de rutas y archivos
  • Iconografía personalizada
  • Documentación completa

Este proyecto representa mi aprendizaje en el desarrollo de aplicaciones de escritorio prácticas y user-friendly, combinando funcionalidad técnica con una experiencia de usuario pulida.
