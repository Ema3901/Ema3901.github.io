creacion.md

Creación

UTTS nació de la necesidad de crear una plataforma de compra y venta diseñada especialmente para estudiantes de la UTTN, facilitando la publicación de artículos, la venta de productos y la comunicación entre usuarios de manera rápida y segura.

Muchas aplicaciones existentes no se adaptaban completamente a las necesidades de los estudiantes, presentando problemas como:

  • Dependencia de plataformas externas: Difícil personalización y falta de control sobre los datos.
  • Limitaciones de alcance: No permitían segmentar usuarios por ubicación dentro del campus.
  • Diseño poco adaptado a móviles: Interfaces no siempre responsivas o intuitivas para estudiantes.
objetivos.md

Objetivos del Proyecto

  • Crear una app móvil intuitiva y accesible para la compra y venta entre estudiantes.
  • Permitir a los usuarios publicar productos, crear su propia tienda y segmentar la ubicación dentro del campus.
  • Integrar comunicación rápida mediante WhatsApp para agilizar la interacción entre compradores y vendedores.
  • Diseñar una interfaz responsiva que funcione correctamente en distintos tamaños de pantalla y dispositivos móviles.
desafios.md

Desafíos Enfrentados

Durante el desarrollo surgieron varios retos importantes:

  • Responsividad: Asegurar que la app se viera y funcionara correctamente en todos los tamaños de pantalla de teléfonos móviles.
  • Integración con Backend: Crear y conectar la app con una API desarrollada en ASP.NET para gestionar la base de datos de usuarios, productos y transacciones.
  • Experiencia del Usuario: Mantener una navegación fluida y funcional, con información clara sobre productos y ubicación de vendedores.
  • Trabajo en Equipo: Coordinación con mi compañero Mario para desarrollar la app de manera ordenada y eficiente.
aprendizajes.md

Lo que Aprendí

  • Diseño Responsivo: Cómo construir interfaces adaptables a diferentes dispositivos móviles.
  • Creación de APIs: Desarrollo y conexión con una API en ASP.NET para manejar datos de usuarios y productos.
  • Desarrollo Híbrido: Uso de Apache Cordova y Node.js para convertir la app web en una aplicación móvil funcional.
  • Trabajo en Equipo: Coordinación y planificación para cumplir con los objetivos del proyecto.
evolucion.md

Evolución del Proyecto

El proyecto comenzó como una idea básica de marketplace para estudiantes y evolucionó a una aplicación móvil completa que incluía:

  • Publicación de artículos y productos
  • Creación de tiendas personales y segmentación por ubicación
  • Integración con WhatsApp para comunicación inmediata
  • Interfaz responsiva y funcional en dispositivos móviles

Este proyecto refleja mi aprendizaje en desarrollo móvil, diseño responsivo y creación de APIs, combinando funcionalidad técnica con experiencia de usuario adaptada al contexto estudiantil.
