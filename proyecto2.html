creacion.md

Creación

CalzadoJJ nació de la necesidad de crear una tienda en línea funcional y atractiva para la venta de calzado, accesible desde cualquier dispositivo.

Muchas tiendas web existentes tienen limitaciones como:

  • Dependencia de plataformas externas: Limitaciones para personalizar totalmente la tienda.
  • Restricciones comerciales: Comisiones o funcionalidades limitadas sin planes pagos.
  • Falta de personalización visual: No permiten adaptar completamente la experiencia al branding.
objetivos.md

Objetivos del Proyecto

  • Crear un catálogo dinámico de productos accesible y responsivo.
  • Permitir a los usuarios realizar compras seguras con datos almacenados en MySQL.
  • Ofrecer una interfaz intuitiva y atractiva usando tecnologías modernas.
  • Hospedar la plataforma de manera estable y accesible al público (Hostinger).
desafios.md

Desafíos Enfrentados

Durante el desarrollo me encontré con varios retos interesantes:

  • Integración Backend-Frontend: Comunicación eficiente entre la base de datos MySQL y la interfaz web dinámica.
  • Diseño Responsivo: Adaptación del catálogo y carrito de compras a distintos tamaños de pantalla usando Bootstrap 5.
  • Experiencia del Usuario: Navegación fluida, validación de formularios y mensajes claros para cada acción.
  • Trabajo en Equipo: Coordinación con Gema Nahomi Vega Rubio para mantener el proyecto ordenado y funcional.
aprendizajes.md

Lo que Aprendí

  • Desarrollo Web Full-Stack: HTML, CSS, JavaScript, jQuery y conexión con MySQL.
  • Creación de Interfaces Responsivas: Diseño adaptado a dispositivos móviles y desktop con Bootstrap 5.
  • Gestión de Proyectos en Equipo: Coordinación y control de versiones.
  • Hosting y Despliegue: Publicación de la tienda en Hostinger de manera estable.
evolucion.md

Evolución del Proyecto

El proyecto comenzó como un prototipo básico de catálogo y evolucionó a una tienda en línea completa. Las mejoras incluyeron:

  • Catálogo de productos dinámico
  • Carrito de compras funcional
  • Validaciones de usuario y mensajes de feedback
  • Diseño responsivo y experiencia completa en distintos dispositivos

Este proyecto refleja mi capacidad de combinar habilidades técnicas con diseño y experiencia de usuario, creando una solución web práctica, atractiva y funcional.
